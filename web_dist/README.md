# MChart web build (deployed artifact)

Generated by `flutter build web --release` in [`app/`](../app), pointed at the
live backend. **Do not hand-edit these files** — regenerate instead:

```bash
cd app
flutter build web --release --no-web-resources-cdn \
  --dart-define=MCHART_API=https://chart.mbuniehub.com \
  --dart-define=MCHART_REALTIME=off
rm -rf ../web_dist
mkdir ../web_dist
cp -r build/web/. ../web_dist/
# re-add web_dist/.htaccess (SPA fallback — see git history) if it was wiped
```

`MCHART_REALTIME=off` until Pusher is configured (Reverb doesn't run on
shared hosting) — see `docs/DEPLOYMENT.md` §8.

Committed instead of built on the server because Hostinger shared hosting has
no Flutter SDK. Unused CanvasKit renderer variants (skwasm, chromium,
debug `.symbols`) are stripped to keep this under ~12 MB.

Serve as a static site — any subdomain/folder docroot pointed at this
directory works, no PHP required.
